# Ariana & Johan — Pearl Modern Classic

Tema undangan pernikahan interaktif bertema mutiara (*Pearl Modern Classic*) buatan [riungin.id](https://riungin.id).

## Menjalankan Pratinjau Lokal
Dari direktori proyek:
```bash
python -m http.server 4175 --directory .
```
Buka browser di: `http://localhost:4175/`

- **Nama Tamu**: Tambahkan query string `?to=Nama%20Tamu` pada alamat URL.
- **State Amplop Terbuka**: Tambahkan query string `?state=opening` untuk langsung melihat animasi amplop terbuka.

## Fitur & Konten Undangan
1. **Interactive Envelope Cover**: Amplop dengan segel lilin mutiara, kartu undangan elegan, dan animasi kelopak mawar.
2. **Interactive Scratch Reveal Photo**: Frame mutiara iridescent dengan kanvas interaktif *scratch-to-reveal* untuk mengungkap foto kenangan mempelai.
3. **The Bride & The Groom**: Oval portrait kedua mempelai dengan sentuhan ornamen bunga dan kaligrafi modern.
4. **Our Keepsake**: Kolase kenangan berestetika vintage modern classic dengan amplop, untaian mutiara hati, frame rococo, dan foto polaroid.
5. **Hari Bahagia Kami**: Jadwal Acara (Pemberkatan & Resepsi) berbingkai *scalloped lace arch* dengan navigasi langsung ke Google Maps.
6. **Countdown Timer & Google Calendar**: Penghitung waktu mundur interaktif dengan tautan langsung *Add to Google Calendar*.
7. **Our Love Story**: *Timeline* perjalanan cinta romantis kedua mempelai.
8. **Captured in Time (Gallery)**: Galeri foto berbingkai kerang mutiara (*Clam Pearl*) dan pita satin (*Satin Ribbon Frame*) dengan modal zoom resolusi penuh.
9. **Dress Code & Gift**: Panduan warna busana formal (*Pearl, Ivory, Sand, Warm Brown, Soft Black*) dan amplop digital.
10. **RSVP & Buku Ucapan**: Formulir konfirmasi kehadiran dan pengiriman ucapan/doa restu.
11. **Closing & Replay**: Frame penutup berenda dengan ucapan terima kasih dan tombol buka kembali amplop cover.
